Screenshots for /guide

File names, exactly like this:

    shot-01.png          taken on a normal screen
    shot-01-mobile.png   taken on a phone

Which screen belongs to which number is written in the slot on the guide page
itself. A slot turns into the image the moment the file exists, so the page
stays readable while they are still being made.

If the mobile version is missing, the desktop one is shown on phones too. That
works, but it renders small - which is the reason for having both.

png or jpg are both fine. Say so if you use jpg and the references get updated.

Take the desktop shots at the same window width, so the page reads evenly.
